# Pualll67-1

Sandbox repository for the DSH super-agent prototype.

## What this repository is for

The agent account **Pualll67** works on this repository. Requests arrive as issues.

This is a sandbox for superagent.

## How to ask for work

Open an issue or comment, and mention the agent account:

```
@Pualll67 please fix <what you want>
```

The agent reads the request and works in its own checkout.

The agent replies in the same issue it was asked in.
