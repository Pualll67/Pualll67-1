# AGENTS.md

## Scope

This is a sandbox repository. Accept only small, self-contained requests:

- fix a typo or wording in the README
- add a short section to the README
- answer a question about the repository

If a request is larger than that, reply with a short note that it is out of scope and stop.

## How to work

1. Read the request.
2. Change at most two files.
3. Commit with a message that says what changed and why.
4. Reply in the issue with a summary. Do not open a pull request unless the request asks for one.
